# v0.1.1

安全、并发与发布流程修复版本，并完善 README 的 MCP 服务说明。工具面与场景格式不变。

## 亮点

- **并发与数据完整性**：同一进程内对同一场景文件的读改写串行执行；整文件写入改为临时文件替换；创建图形使用排他写入，并发创建同名图形只有一方成功。
- **元素操作修复**：更新补丁在写入前校验可渲染性（拒绝 `isDeleted: true`）；删除元素后刷新被清理元素的版本并回收不再被引用的嵌入图片；`replace` 允许复用被替换列表中的 id。
- **路径安全**：工作区根、`workspace` 参数与文件路径都会解析软链接后再校验包含关系；截图路径限定 `.png`。
- **输入校验**：元素补丁的数值字段要求有限数字，`id`/`type` 不可修改；折线点限制 2–1024 个 `[x,y]`；坐标与尺寸限范围；未知图形类型与布局动作直接报错。
- **HTTP 加固**：非回环地址必须配置 `--token`；token 常量时间比较；拒绝非回环 `Origin`；请求体上限 64 MiB、在途请求上限 32、请求/头部超时 5 分钟/15 秒；修正 IPv6 与通配地址的监听 URL。
- **图片与截图**：外部图片上限 10 MiB，并按文件头校验实际类型与扩展名一致；截图 PNG 上限 16 MiB，写入采用临时文件替换。
- **渲染器**：关闭流程保证释放无头浏览器；渲染出错时丢弃并重建浏览器；桥接页保留场景 `appState`；PNG 编码改为分块转换。
- **发布与 CI**：移除断链的 `./src/*` 导出；新增 `prepublishOnly` 与 `noEmitOnError`；CI 收窄权限、增加并发组与超时；第三方 Action 固定到 commit SHA；Release 关闭凭据持久化、按版本串行并拒绝覆盖已存在的 tag/Release；Chrome 固定为 157。
- **文档**：README 新增快速开始；「作为 MCP 服务」补充传输对比、协议行为、状态码、鉴权与多工作区说明。

## 兼容性变更

- MCP 业务失败结果由纯文本改为结构化 JSON `{ "ok": false, "error": "<原因>" }`；按文本解析错误分支的客户端需要调整。入参 schema 校验错误仍返回 `MCP error -32602` 文本。
- `excalidraw_screenshot` 的 `path` 必须以 `.png` 结尾，否则在调用前被拒绝。
- 监听非回环地址时必须提供 `--token`，否则服务拒绝启动。
- 空白的 `workspace` / `drawing` 参数在入参校验阶段被拒绝，不再静默落到默认目标。
- `excalidraw_element_create` 的图片元素必须引用场景 `files` 中已存在的 `fileId`。
- `excalidraw_element_update` 拒绝把 `isDeleted` 设为 `true` 的补丁。

## 安装

从本 Release 下载 `reachforstar-excalidraw-tools-0.1.1.tgz`，然后执行：

```sh
npm install -g ./reachforstar-excalidraw-tools-0.1.1.tgz
excalidraw-mcp --version
```

源码安装与客户端配置见 [README](https://github.com/ReachForStar/excalidraw-tools-mcp#readme)。
