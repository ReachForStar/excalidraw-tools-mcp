# v0.1.0

首个公开版本，提供可独立运行的 Excalidraw MCP 服务与 cordis 插件。

## 亮点

- **18 个 MCP 工具**：场景读写、原生 `.excalidraw` 导入导出、多图形管理、元素增删改查、对齐/分布/分组/锁定/复制、图片插入、画布描述与 PNG 截图。
- **两种传输**：默认 stdio；`--http` 使用无状态 Streamable HTTP，支持多工作区与 Bearer token。
- **官方渲染**：SVG/PNG 导出复用 Excalidraw 官方实现，在本机无头 Chrome 中渲染，保留手绘纹理、自动换行与嵌入图片。
- **工作区隔离**：所有路径限制在启动时传入的 `--workspace` 内；`--scene` 由运维指定，模型无法改写。
- **全局命令**：`excalidraw-mcp` 支持源码运行、本地 tarball 全局安装；修复了全局 bin 符号链接入口静默退出的问题。

## 安装

从本 Release 下载 `reachforstar-excalidraw-tools-0.1.0.tgz`，然后执行：

```sh
npm install -g ./reachforstar-excalidraw-tools-0.1.0.tgz
excalidraw-mcp --version
```

源码安装与客户端配置见 [README](https://github.com/ReachForStar/excalidraw-tools-mcp#readme)。

## 说明

- 导出 SVG/PNG 需要本机 Chrome/Chromium；`.excalidraw` 导入导出不需要浏览器。
- 当前版本未发布到 npm；请使用本 Release 的 tarball 或源码构建。
- HTTP 公网部署必须使用 HTTPS，并设置 `--token`。
